# Local setup checklist (manual)

## Minimal checklist
- [ ] WordPress installed
- [ ] Blocksy installed (parent theme)
- [ ] Copy custom plugins into wp-content/plugins
- [ ] Copy blocksy-child into wp-content/themes
- [ ] Activate plugins + child theme
- [ ] Import CPT UI export (collector CPT)
- [ ] Confirm ACF field groups loaded from `blocksy-child/acf-json`

## Smoke test
- [ ] Open Collector archive page (archive-collector.php in effect)
- [ ] Open a single collector page (single-collector.php in effect)
- [ ] Open Overview stats page (plugin page/shortcode working)
- [ ] Open SVG map page (interaction works)
- [ ] Homepage slider renders
